# QuanNet

## Installation

1. Install [APBS 3.4.1](https://apbs.readthedocs.io/en/latest/getting/index.html#installing-from-pre-compiled-binaries)
from pre-compiled binaries
2. Install quannet Python package:

```commandline
pip install -e .
```

## Usage:

### Train:
```commandline
quannet mode=train data=strucutres/train.csv
```
